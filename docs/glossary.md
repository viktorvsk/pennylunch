# Glossary

## Recipe

Definition: A source recipe imported from the gzip dataset and stored with typed columns for search and display.
Owner: Recipe discovery.
Notes: Imported from the recipe gzip source.

## Source-Shaped JSON

Definition: A JSON object reconstructed from recipe columns with the same fields and values as the original source payload.
Owner: Recipe import.
Notes: Import specs compare source-shaped JSON from the database with parsed gzip JSON.

## Ingredient Vector

Definition: A 384-dimension pgvector embedding generated from a recipe's non-optional canonical Ingredient names.
Owner: Ingredient search.
Notes: Vectors are nullable and generated by a maintenance task after import.

## Ingredient Name

Definition: A raw ingredient name emitted by `ingredient-parser-nlp` for a recipe source ingredient line.
Owner: Ingredient search.
Notes: Stored in `recipes.ingredient_names` and shown in recipe cards. These names must not be overwritten with canonical Ingredient names. Non-optional canonical names are resolved from the catalog when generating recipe vectors.

## Ingredient Alias

Definition: A reviewed alternate phrase for an Ingredient, such as a plural, preparation-specific, or source-parser-specific name.
Owner: Ingredient search.
Notes: Stored in `ingredients.aliases` as a JSONB array and maintained in `config/ingredient_aliases.yml`. Alias uniqueness is enforced by case-and-whitespace-normalized lookup key so each raw phrase maps to exactly one canonical Ingredient name. Plurals and source-specific variants must be explicit aliases.

## Optional Ingredient

Definition: A catalog Ingredient that is useful for display but should not affect vector search because users commonly have it by default.
Owner: Ingredient search.
Notes: Stored as `ingredients.optional`. Optional ingredients remain selectable in the basket with half opacity, but they are omitted from basket filter submissions and recipe vector text.

## Ingredient Parse Data

Definition: Structured `ingredient-parser-nlp` output stored per source ingredient line, including name, amount, unit, preparation, comments, purpose, confidence values, flags, and parser sentence.
Owner: Ingredient search.
Notes: Stored in `recipes.ingredient_parse_data` as JSONB for future ranking, explanations, or missing-ingredient features.
